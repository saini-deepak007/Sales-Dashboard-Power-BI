# Sales Performance Dashboard (2020–2022)

An interactive and visually rich Excel dashboard designed to analyze sales data across multiple product categories, brands, and geographical regions. This project enables stakeholders to gain a comprehensive overview of business performance metrics for the years 2020 through 2022, supporting data-driven sales strategy and operational optimization.

# 🧾 Overview
This dashboard provides actionable insights into sales performance using a clean, dynamic layout powered by Excel's data visualization tools. It displays key performance indicators (KPIs) such as total sales, profit, quantity sold, and transaction volume. It also highlights top-performing product categories, brands, sales by region, and supervisor-level breakdowns.

# 🎯 Objectives
Track and analyze sales data from 2020 to 2022.

Identify best-selling categories and most profitable brands.

Understand geographic distribution of sales across states.

Monitor sales performance by supervisor to evaluate individual contributions.

Improve strategic decision-making using real-time data visualization.
